# PurrSh3ll — Python dependencies (pinned)
#
# This is the single source of truth for the app's PyPI dependencies.
# install.sh installs from this file (`pip install -r requirements.txt`),
# then handles the non-PyPI pieces it cannot: QTermWidget (custom wheel),
# system apt packages, aichat binary, docker images and Ollama.
#
# Why requirements.txt and not pyproject.toml:
#   PurrSh3ll is an application run directly via `python3 main.py`, not a
#   distributable package (`pip install .`). pyproject's build-system /
#   entry-point machinery would go unused, and install.sh is still required
#   for the apt/wheel/binary steps regardless. A pinned requirements.txt is
#   the better fit here.
#
# Versions are pinned exactly (==) so test runs and fresh installs are
# reproducible. Bump deliberately after verifying, not implicitly.
